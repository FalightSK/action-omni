# Camera-ready manuscript

`main.tex` is the six-page IEEE manuscript. It preserves the author block,
copyright line, 13 references, historical ALOHA failure analysis, and the
separation between submitted, fixed-endpoint, and later campaigns.

The included ALOHA comparison figure is generated by `plot_figures.py` from
`../tmp/experiment_result/action_omni_experiment_results_2026-10-21`.
The script verifies every byte count and SHA-256 in that bundle's 60-file
manifest before plotting. It checks 37 ALOHA checkpoint/loss pairs and that
LIBERO per-task counts sum to each of the three final policy totals. The
figure uses the first and final measured checkpoints of the four complete
ALOHA trajectories. Missing checkpoint probes are never assigned zero success.

Run `python plot_figures.py` from this directory with Matplotlib installed to
rebuild the figures. Compile `main.tex` with the Codex document editor or a
standard LaTeX installation. The manuscript checks the six-page limit at
compile time.

The latest ALOHA checkpoint sweep uses development starts and does not provide
a held-out final result. The three LIBERO final evaluations use held-out
starts, but only one Qwen training seed has a completed final evaluation.

The central question is whether the released robot-adapted VLM endpoint
provides better frozen features for a new manipulation action head than its
stock lineage origin. ALOHA has one fixed instruction, a top camera, and robot
state; it is not an image-only ablation. LIBERO-Goal has task-varying
instructions, two views, and robot state. The benchmarks differ in other
ways, and the intermediate Cosmos checkpoint was not tested, so the paper
does not attribute an outcome specifically to robot pretraining or language.
